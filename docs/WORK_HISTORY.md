## 2026-09-29 실제 앱 적용 상세

- 기존 사이드바·대화 영역의 크기와 배치를 유지하면서 말풍선·브랜드·인용문 색을 변경했다.
- 사용자 디렉터리의 빈 안내 화면을 검색/필터 가능한 목록과 DM 버튼으로 확장했다.
- 일정 패널, 다음 일정 요약, 등록/수정 dialog, 취소 확인 UI를 추가했다.
- 서버의 멤버십/등록자 권한, 개인 일정 비공개, 잘못된 시간/장소 거부, revision 충돌, 수정/취소 후 알림 무효화를 구현했다.
- 미확인 알림을 서버에 저장하고 재접속 시 조회한다. 실행 중 5초 간격으로 확인하며 Electron 최소화 중에도 팝업을 띄운다. 앱 내 확인/5분 연기와 팝업 채널 이동을 연결했다.
- 기존 공감·답장·첨부파일·읽음 기능을 유지했다. 운영 배포와 기존 데이터 이동은 수행하지 않았다.

검증 당시 backend 87개 중 85개 통과/2개 Redis 검사 스킵, 신규 일정 통합 5개 통과. 프런트 타입/데스크톱/웹 빌드, Electron 회귀/알림, Playwright 일정 및 레이아웃 검사가 통과했다. 코드 위치와 제약은 [인수인계](CODEX_HANDOFF.md)에 정리했다.

## Git으로 전달하는 것과 별도 데이터

전달: 전체 tracked 소스와 새 구현 파일, Maven/npm lock 및 wrapper, SQL migration V1–V7, 테스트, 아이콘/알림 리소스, 더미 HTML/화면 이미지, 설정 예제, 실행/배포 스크립트, IntelliJ 실행 구성, 인수인계 문서.

제외: node_modules/target/out/release, 실제 properties/.env, DB 파일/볼륨, 사용자 업로드 첨부, 토큰/쿠키/인증서/터널 credentials, 개인 Codex 세션 원문. 이 파일들은 소스가 아니며 재설치 또는 별도 데이터 이전 대상이다. 로컬 업로드는 삭제하지 않고 ignore 처리했다.

기존 사용자 변경을 덮어쓰지 않았고, 원격 이력을 강제 재작성하지 않는다. 전달된 커밋은 `git log`로 확인한다. 새로운 맥북에서 첫 작업은 문서에 따른 환경 확인과 실행이며, 별도 새 기능 요구가 확정되어 있는 상태는 아니다.

## push 준비 시 재현 확인 (2026-09-29)

실제 Git index에 포함된 파일만 임시 디렉터리로 내보내 새 장비처럼 검사했다. 원래 작업 폴더의 node_modules, 실제 properties, DB 파일, 빌드 결과를 가져오지 않았다.

- `npm ci`: lockfile로 신규 설치 완료.
- `npm run typecheck`, `npm run build`, `npm run build:web`: 모두 통과.
- `./mvnw test`: 87개 중 85개 통과, 실패/오류 0, 외부 Redis 연결 검사 2개 스킵.
- 인수인계 문서의 상대 링크, `git diff --cached --check`, 실제 설정/업로드 등 제외 여부 확인.

전체 코드와 문서는 `main`의 이번 전달 커밋에서 함께 관리한다. 이 재현 검증은 로컬 개발 스택 전체의 실제 로그인이나 대상 회사 환경 배포를 대신하지 않는다.
